# Shift Scheduler

The legacy application remains at index.html. This branch adds Phase 1–4 pilot of V2 at v2/index.html; it is not deployed or production-ready.

See [Phase 1 setup and verification](docs/PHASE1_SETUP.md). Supabase project and Auth accounts must be configured separately. Do not commit employee records, payroll files or secret keys.

Scope: Employee master, employment history, compensation history, role-based access and audit metadata. Phase 2 adds shared schedules, versioned confirmation, and per-period availability. Phase 3 adds manual paper-card attendance, verification, owner approval and immutable revision history. Phase 4 adds cash advance requests, approval, actual payment recording and revision history. No payroll calculation, deductions or legacy data migration yet. See [Phase 2 setup and tests](docs/PHASE2_SETUP.md).
