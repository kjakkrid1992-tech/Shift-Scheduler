# 7.9 RC2 — attendance worksheet
Default Attendance mode is whole pay period. Load MM/YYYY + department (confirmed schedule required); select employee; edit dates inline, copy completed single-slot planned times into blank rows, or select days and apply a preset. Explicitly verify actual time, breaks, exceptions, and normal/OT. No automatic off from empty schedule. New/draft only editable; verified owner approvals selected together. Daily mode retained for reopening and revision history. Existing RPCs unchanged; no new database migration. Each selected day is saved and optionally verified separately; partial success shown, successful entries retained; stale rows require reload. Future dates disabled; incomplete shifts cannot be saved as actual work. Historical exercise requires isolated database if closing or recording simulated payments; rates effective only from actual approved date.
