# V8 field pilot usability
Home is the landing view for Manager/Owner, with actual period summary and task shortcuts. Attendance opens automatically for all departments; click a person, select actual shift or off/leave/absence on each row, use custom time only for exceptions. No selection is necessary for ordinary save or send; checkboxes are only for optional repeated entry. Owner approves verified dates of the selected person. Confirm a schedule first; link to schedule opens same period and department. Existing database and RPCs unchanged. Pay period can be changed by calendar or previous/current/next. Use Excel in parallel; do not close historical simulated payroll or record fake payment in production. No data migration. This release improves primary flows; real browser and staff feedback remain necessary.
